A client application for allowing meta quest to connect to VR treadmill. 
Loosely based on:  https://www.youtube.com/watch?v=kbBYcVrGZus up to 14:41
Need XR interaction toolkit 3.0.7
Need XR origin (from samples prefabs as it is already set up with linkages), XR interaction Manager, XR events
